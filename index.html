Projects

JobLookout

A job-alert pipeline that polls the job boards of 180+ companies and sends each subscriber the new postings that match their filters, as Discord messages.

Status
Built solo; running on AWS EC2 since Mar 2026
Stack
Node.js, SQLite, Playwright, discord.js, Next.js
Live
joblookout.app (source is private)
  • Three polling lanes instead of one loop. High-churn APIs poll every ~3 s, standard ATS APIs rotate in batches of 20 to stay under rate limits, and Playwright scrapers run every 5 minutes on one shared headless browser to amortize startup cost.
  • SQLite in WAL mode, not a database server. Several processes write to one database file; writes are serialized and retried when the file is locked, so there is still no database server or connection pool to run. Dedupe lookups stay under a millisecond at 6,000+ rows.
  • Filter at delivery, not at collection. Polling cost grows with the number of companies, not subscribers: per-user polling would cost O(users × companies) requests, while one shared pass costs O(companies).

As of September 2026: 15+ users, 6,000+ postings tracked, and 5,000+ alerts delivered.
